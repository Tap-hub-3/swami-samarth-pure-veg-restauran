# Shri Swami Samarth Family Restaurant & Fast Food Center

Static website (HTML, CSS, vanilla JS). Works on GitHub Pages.

## Edit your details
Open `js/menuData.js` and change: WhatsApp number, phone, address, map link, hours, dishes and prices.

## Add photos
See `IMAGE_CHECKLIST.md`. Missing photos show a neat placeholder until you add them.

## Publish on GitHub Pages
1. Create a repository and upload all files (keep the folder structure).
2. Settings > Pages > Source: "Deploy from a branch" > main / (root).
3. Your site goes live at https://<username>.github.io/<repository>/
